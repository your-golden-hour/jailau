# Жайлау

Студенческий сайт заявок на поездки между Шымкентом и сёлами на русском и
казахском языках. Статический интерфейс, Supabase Auth/PostgreSQL/RLS,
никаких платных API. Оплата поездки — наличными напрямую водителю.

Локальный просмотр из папки проекта:

```text
python -m http.server 8766
```

Откройте `http://localhost:8766/`. Демо-режима больше нет: для входа нужен
email-аккаунт Supabase с подтверждённой почтой. Google-вход подготовлен в коде,
но провайдер пока не включён владельцем. Для подтверждения email Supabase
нужно разрешить локальный адрес в Authentication → URL Configuration.

После входа заполните профиль и проверьте контактный номер. В проекте пока нет
проверенных зон и сёл; реальные заявки нельзя создавать до их добавления.

`main` — рабочая ветка; `release` предназначена только для проверенной версии.
Cloudflare Pages не публикуется без согласия владельца. Никаких паролей,
`service_role` или настоящих данных людей в репозитории.

Состояние и следующие шаги: [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md).
Настройка Supabase: [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md).
